在线订餐系统

Spring Boot + MySQL + Redis

📋 项目介绍

全栈在线订餐平台，支持菜品管理、订单系统、支付集成、实时配送跟踪。采用微服务架构，实现高并发场景下的订单处理。

✨ 核心功能

  • ✓ 用户与商家管理系统
  • ✓ 菜品分类展示与搜索
  • ✓ 购物车与订单管理
  • ✓ 支付宝/微信支付集成
  • ✓ Redis缓存优化
  • ✓ 实时订单状态推送

🔧 技术栈

Spring Boot Spring Data JPA MySQL Redis RabbitMQ JWT Docker

📊 项目成果

系统支持日均1000+订单，订单处理响应时间<100ms，支付成功率99.8%，用户满意度4.8 /5。
