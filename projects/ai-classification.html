AI文本分类系统

Python + TensorFlow + FastAPI

📋 项目介绍

基于深度学习的文本分类平台，支持新闻分类、情感分析、垃圾邮件检测等多个场景。使用CNN和LSTM模型组合，准确率达到96%。

✨ 核心功能

  • ✓ 多分类文本识别
  • ✓ 情感分析（积极/消极/中立）
  • ✓ 实时预测API
  • ✓ 模型训练与优化
  • ✓ 性能可视化面板
  • ✓ 批量预测支持

🔧 技术栈

Python TensorFlow Keras FastAPI Scikit-learn Pandas Docker

模型精准度96.2%，召回率94.8%，处理速度500条/秒，已应用于内容审核系统。
